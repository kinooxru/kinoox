Совместный просмотр видео
Организуйте синхронный просмотр видео с друзьями и зрителями в реальном времени.
Живое демо
Работающий пример плеера с синхронизацией. Откройте несколько вкладок с этой страницей — управление плеером автоматически синхронизируется между ними.


Подключение за 4 шага
Шаг 1: Тег плеера с data-sync
<ins data-publisher-id="674093403"
     data-type="movie"
     data-id="1"
     data-sync="true"></ins>
Шаг 2: Подключите rendex-sdk
<script src="https://graphicslab.io/sdk/v2/rendex-sdk.min.js" async></script>

            
<script src="https://alt.graphicslab.io/sdk/v2/rendex-sdk.min.js" async></script>
Шаг 3: Подключите sync-lib
<script src="https://sync.videoframe2.com/sync-lib.js"></script>
Шаг 4: Инициализируйте
<script>
new WatchParty({
    iframe: '#vibix-frame-id',   // Селектор iframe
    roomId: 'example_room_12345' // ID комнаты (необязательно)
});
</script>
Полный пример
<!DOCTYPE html>
<html lang="ru">
<head>
    <script src="https://graphicslab.io/sdk/v2/rendex-sdk.min.js" async></script>
</head>
<body>

    <!-- Плеер с совместным просмотром -->
    <ins id="vibix-frame-id"
         data-publisher-id="674093403"
         data-type="movie"
         data-id="1"
         data-sync="true"></ins>

    <!-- Библиотека синхронизации -->
    <script src="https://sync.videoframe2.com/sync-lib.js"></script>

    <script>
    new WatchParty({
        iframe: '#vibix-frame-id'
    });
    </script>
</body>
</html>
Параметры
Параметры плеера
data-sync — совместный просмотр ("true")

Параметры WatchParty
iframe — CSS-селектор IFRAME (обязательно)
roomId — ID комнаты (если не указан, генерируется автоматически)
username — имя зрителя (если не указано, генерируется автоматически)
wsServer — WebSocket-сервер (по умолчанию wss://sync.videoframe2.com)
debug — логи в консоль ("true"/"false")

Как это работает?
Для создателя комнаты:
Откройте страницу с видео
Автоматически создастся комната с уникальным ID
Нажмите кнопку "Скопировать ссылку" в виджете справа
Отправьте ссылку друзьям (через мессенджер, соцсети и т.д.)
Управляйте просмотром — ваши действия синхронизируются со всеми зрителями
Для зрителей:
Перейдите по ссылке, которую отправил ведущий
Автоматически подключитесь к комнате
Смотрите синхронно — все действия ведущего повторяются у вас
Особенности синхронизации
Все действия ведущего автоматически повторяются у зрителей. Отставание корректируется без участия пользователя.

Воспроизведение

⏸️
Пауза
Остановка видео мгновенно применяется ко всем

Перемотка
Позиция воспроизведения выравнивается у всех зрителей

📺
Смена серии / озвучки
Переключение сезона, эпизода или аудиодорожки синхронизируется

🔄
Автосинхронизация
Если у зрителя возникает отставание, система автоматически выравнивает позицию без разрыва просмотра
