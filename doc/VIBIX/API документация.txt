GET /api/v1/publisher/videos/kp/{kpId} - Получить загруженное видео по Киопоиск ID

Параметры:

kpId: integer	Kinopoisk ID видео (обязательный)
Пример: 484488

Ответ:

id: integer	ID видео
Пример: 100
name: string	Название видео на русском либо на английском
name_rus: string	Название видео на русском (может быть null)
name_eng: string	Название видео на английском (может быть null)
name_original: string	Оригинальное название видео (может быть null)
type: string	Тип видео: movie или serial
year: integer	Год выпуска видео (может быть null)
kp_id: integer	ID видео на Кинопоиске (может быть null)
kinopoisk_id: integer	[Устарело] ID видео на Кинопоиске (может быть null)
imdb_id: string	ID видео на IMDb (может быть null)
kp_rating: float	Рейтинг на Кинопоиске (может быть null)
imdb_rating: float	Рейтинг на IMDb (может быть null)
iframe_url: string	URL фрейма видео
poster_url: string	URL постера (может быть null)
backdrop_url: string	URL широкоформатного постера (может быть null)
duration: integer	Длительность видео в минутах (может быть null)
quality: string	Качество видео
genre: array of strings	Жанры видео (может быть null)
country: array of strings	Страны производства видео (может быть null)
description: string	Описание видео (может быть null)
description_short: string	Краткое описание видео (может быть null)
voiceovers: array	Список озвучек (может быть null)
- id: integer	ID озвучки
- name: string	Название озвучки
tags: array	Список тегов (может быть null)
- id: integer	ID тега
- code: string	Код тега
- name: string	Название тега
uploaded_at: string	Дата и время добавления видео (может быть null)

GET /api/v1/publisher/videos/links - Получить список загруженных видео

Параметры:

type: string	Тип видео: movie или serial
category[]: array of integers	Категории видео
year[]: array of integers	Годы выпуска
genre[]: array of integers	Жанры видео
country[]: array of integers	Страны производства видео
tag[]: array of integers	Теги видео
voiceover[]: array of integers	Озвучки видео
page: integer	Номер страницы (по умолчанию: 1)
limit: integer	Количество записей на странице (по умолчанию: 20)
updated_from: string	Дата в формате ISO 8601. Возвращает только видео, изменённые после указанной даты.
Пример: 2026-06-28T14:30:00

Ответ:

data: array

Массив объектов VideoLinkResource
- id: integer	ID видео
- name: string	Название видео
- name_rus: string	Название на русском (может быть null)
- name_eng: string	Название на английском (может быть null)
- type: string	Тип видео
- year: integer	Год выпуска (может быть null)
- kp_id: integer	ID на Кинопоиске (может быть null)
- imdb_id: string	ID на IMDb (может быть null)
- iframe_url: string	URL фрейма
- poster_url: string	URL постера (может быть null)
- quality: string	Качество видео
- uploaded_at: string	Дата добавления
links: object	Ссылки пагинации
- first: string	URL первой страницы
- last: string	URL последней страницы
- prev: string|null	URL предыдущей страницы (может быть null)
- next: string|null	URL следующей страницы (может быть null)
meta: object	Метаданные пагинации
- current_page: integer	Текущая страница
- from: integer	Начальный индекс записей
- last_page: integer	Последняя страница
- links: array	Ссылки для навигации
-- url: string|null	URL страницы (может быть null)
-- label: string	Подпись ссылки
-- active: boolean	Активна ли ссылка
- path: string	Базовый путь
- per_page: integer	Записей на странице
- to: integer	Конечный индекс записей
- total: integer	Всего записей
success: boolean	Успех операции
message: string	Сообщение
