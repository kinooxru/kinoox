Спроектируй и создай с нуля веб-приложение и нативные приложения — онлайн-кинотеатр нового поколения на домене KINOOX.RU (аналог Anixart, но визуально превосходящий всё, что есть на рынке). DLE, WordPress и любые CMS НЕ используем. PWA НЕ используем. Пишем всё с нуля.

## Философия проекта

1. **Тотальная модульность.** Каждый компонент — независимый модуль со своим интерфейсом. Заменяемый, отключаемый, расширяемый без затрагивания остального. Сайт, API, мобильное приложение, десктопное приложение — отдельные пакеты в монорепозитории, связанные только через shared-типы и API-контракт.

2. **Дизайн нового поколения.** Уникальная тема, которой нет нигде. Не Material, не iOS, не Bootstrap, не Tailwind-шаблоны. Своя дизайн-система с нуля: палитра, типографика, анимации, переходы, поведение карточек, плеера, навигации. Бренд KINOOX — кастомный логотип ?? с градиентом. Цель — чтобы пользователь с первого экрана понял: этого он ещё не видел.

3. **Полноценные нативные приложения.** НЕ PWA, НЕ веб-обёртка. Отдельные нативные приложения:
   - Android — React Native (APK)
   - iOS — React Native (TestFlight / Ad Hoc)
   - Windows — Tauri 2 (нативный .exe / .msi)
   - macOS — Tauri 2 (нативный .dmg)
   - Linux — Tauri 2 (.AppImage / .deb / .rpm)
   Каждое приложение — полноценный клиент с собственным UI, офлайн-кэшем, нативными жестами и системной интеграцией.

4. **Страница загрузки приложения.** Отдельная landing-страница /download с полным описанием, скриншотами, возможностями и кнопками скачивания для всех платформ. Страница — часть сайта, но визуально самостоятельная.

5. **Продакшн-сервер:** Intel Core i7-6700 (4 ядра / 8 потоков), 64 ГБ RAM, 2?512 ГБ SSD. ОС: Debian 12 (Bookworm). IP: 95.216.97.185. Развёртывание через Docker + Nginx. Ресурс-оптимизация: PostgreSQL max_connections=100, shared_buffers=16GB, Redis maxmemory=4GB, Node.js --max-old-space-size=4096. Кэширование всего: постеры через CDN балансеров, API-ответы через Redis, SSR-страницы через ISR и Nginx cache. Docker memory limits: postgres 32G, redis 4G, api 8G, web 8G. Swap 4 ГБ.

### Визуальные элементы (web, mobile, desktop — единый язык)

1. **Карточки тайтлов**
   - Скруглённые (20px), мягкое внутреннее свечение по периметру
   - При наведении/тапе: постер увеличивается, градиентная вуаль снизу с инфо
   - Рейтинг — число в круглом бейдже с градиентом flux (>7) или серым (<7)
   - Мягкое свечение flux-prism за карточкой при наведении

2. **Плеер**
   - Выезжает снизу с easing cubic-bezier(0.16, 1, 0.3, 1), экран затемняется
   - Контролы — кастомные, glassmorphism, появляются при тапе, исчезают через 3 сек
   - Прогресс-бар — градиентный flux ? prism, пульсирующая точка
   - Переключение источников (Vibix / Veoveo) — анимированные табы снизу

3. **Навигация**
   - Web: шапка с smart-hide (прячется при скролле вниз, выезжает при скролле вверх), glassmorphism, expandable-поиск
   - Mobile: bottom tabs с glassmorphism, активный индикатор — градиентная полоска flux-prism
   - Desktop: кастомный заголовок окна (frameless), меню сверху, системный трей

4. **Переходы между экранами**
   - Morphing: контент выезжает снизу с scale(0.95 ? 1) и opacity(0 ? 1)
   - Длительность: 400ms, easing: cubic-bezier(0.16, 1, 0.3, 1)

5. **Загрузка (loading states)**
   - Скелетоны с shimmer-эффектом
   - Полноэкранная — пульсирующий логотип ??

6. **Микроанимации**
   - «В закладки»: heart-burst, иконка меняет цвет на flux
   - Лайк комментария: ripple-эффект
   - Смена качества плеера: morph-переход

### Мобильное приложение — нативные особенности

- React Native с нативными модулями, НЕ веб-обёртка
- Плеер — fullscreen, жесты: свайп влево/вправо — перемотка 10 сек, свайп вверх — следующая серия, свайп вниз — выход из плеера
- Pull-to-refresh с кастомным лого ??
- Офлайн-режим: кэширование описаний и постеров в AsyncStorage
- Push-уведомления: выход новых серий (Firebase Cloud Messaging для Android, APNs для iOS)
- Системная интеграция: picture-in-picture, Chromecast (Android), AirPlay (iOS)
- Сплит-скрин на iPad

### Десктопное приложение — нативные особенности (Tauri 2)

- Полностью нативный бинарь, НЕ Electron, НЕ веб-обёртка
- Окно без рамок (frameless) с кастомным заголовком в стиле glassmorphism
- Системный трей с быстрым доступом: «Продолжить просмотр», «Поиск», «Выход»
- Горячие клавиши: Ctrl+F — поиск, Ctrl+D — закладка, Space — пауза, Esc — выход из плеера
- Мини-плеер (picture-in-picture, всегда поверх окон)
- Автозапуск с системой (опционально)
- Нативные уведомления ОС о новых сериях
- Размер приложения: ~5–10 МБ (Tauri, в отличие от Electron ~80+ МБ)

  async getPlayer(kpId: number): Promise<PlayerSource | null> {
