# Дизайн-система «Cinematic Flow»

Уникальная тема KINOOX: не Material, не iOS, не Bootstrap, не готовые
Tailwind-шаблоны. Собственная палитра, типографика, анимации и поведение
компонентов. Единый визуальный язык для сайта, мобильных и десктопных
приложений.

## Палитра

### Базовые поверхности

| Токен | Значение | Назначение |
|---|---|---|
| `--color-void` | `#06070A` | Фон, глубже чёрного |
| `--color-abyss` | `#0C0E14` | Карточки, панели |
| `--color-surface` | `#131620` | Elevated-поверхности |
| `--color-frost` | `#1C2030` | Бордеры, разделители |

### Акценты — всегда градиентные, не плоские

| Токен | Градиент | Применение |
|---|---|---|
| flux | `135deg, #FF3D6E → #FF6B3D` | Логотип, основные кнопки, рейтинг > 7, полоска активного таба |
| prism | `135deg, #7C5CFF → #5C8CFF` | Вторичные действия, аватар, сезоны |
| aura | `135deg, #00E5C7 → #00B8E5` | Иконки особенностей, статус «Выходит» |
| flux → prism | `90deg, #FF3D6E → #7C5CFF` | Прогресс-бар плеера, индикатор активного таба |

### Текст

| Токен | Значение |
|---|---|
| `--color-text-primary` | `#F5F7FA` |
| `--color-text-secondary` | `#8B92A8` |
| `--color-text-muted` | `#4A5068` |

### Эффекты

```css
--glow-flux:  0 0 40px rgba(255,61,110,0.3);
--glow-prism: 0 0 40px rgba(124,92,255,0.25);
--glow-aura:  0 0 40px rgba(0,229,199,0.2);
--blur-glass: blur(20px) saturate(1.5);
```

## Типографика

| Роль | Шрифт | Размер |
|---|---|---|
| Заголовки | Space Grotesk | `clamp(2.5rem, 6vw, 5rem)` — hero, `clamp(1.75rem, 3vw, 2.5rem)` — h1 |
| Основной текст | Inter | `clamp(0.875rem, 1vw, 1rem)` |
| Технические элементы | JetBrains Mono | `clamp(0.75rem, 0.8vw, 0.875rem)` |

Рейтинги, версии, размеры файлов и системные требования набираются моноширинным
шрифтом — это отличительная черта системы.

## Радиусы и сетка

- карточки тайтлов — **20px**
- панели и hero-блоки — **28px**
- контролы (кнопки, поля) — **12px** и `9999px` для капсул
- шаг сетки отступов — 4px
- постер в сетке — соотношение `2 / 3`, backdrop — `16 / 9`

## Анимации

Основная кривая всего интерфейса:

```css
--ease-flow: cubic-bezier(0.16, 1, 0.3, 1);
```

| Действие | Длительность | Описание |
|---|---|---|
| Переход между экранами | 400 мс | Снизу, `scale(0.95 → 1)`, `opacity(0 → 1)` |
| Выезд плеера | 400 мс | Снизу на всю высоту, экран затемняется |
| Шапка (smart-hide) | 260 мс | Прячется при скролле вниз, выезжает вверх |
| Наведение на карточку | 260 мс | Постер `scale(1.08)`, свечение flux-prism за карточкой |
| Контролы плеера | — | Исчезают через 3000 мс бездействия |
| Скелетон | 1400 мс | Пробегающий блик |
| Логотип при загрузке | 1800 мс | Пульсация `scale(1 → 1.06)` |
| «В закладки» | 520 мс | Heart-burst: `1 → 1.35 → 0.92 → 1.08 → 1` |
| Лайк комментария | 600 мс | Ripple: `scale(0 → 2.4)`, `opacity(0.5 → 0)` |
| Смена качества плеера | 260 мс | Morph: `translateY(6px) scale(0.96 → 1)` |

Все анимации отключаются при `prefers-reduced-motion: reduce`.

## Компоненты

### Карточка тайтла

- скругление 20px, мягкое внутреннее свечение по периметру
  (`inset 0 0 0 1px rgba(245,247,250,0.06)`)
- при наведении постер увеличивается, снизу проявляется градиентная вуаль с инфо
- рейтинг — число в круглом бейдже: градиент flux при значении > 7, серый при меньшем
- при наведении за карточкой появляется свечение flux-prism

### Плеер

- выезжает снизу с кривой `cubic-bezier(0.16, 1, 0.3, 1)`
- контролы — стеклянные (glassmorphism), появляются при движении
- прогресс-бар — градиент flux → prism с пульсирующей точкой
- переключение источников Vibix / Veoveo — анимированные капсулы снизу

### Навигация

| Платформа | Решение |
|---|---|
| Web | Шапка со smart-hide, стекло, expandable-поиск по Ctrl+K |
| Mobile | Bottom tabs со стеклом, активный индикатор — градиентная полоска |
| Desktop | Frameless-заголовок окна, меню сверху, системный трей |

### Загрузка

- скелетоны с shimmer-эффектом
- полноэкранная загрузка — пульсирующий логотип KINOOX

## Логотип

Знак — силуэт инфузории-туфельки с градиентом flux и ресничками.
Wordmark — «KINOOX» капсом с разрядкой `0.22em`.

## Tailwind

Конфигурация сайта (`apps/web/tailwind.config.mjs`) повторяет токены:
цвета `void`, `abyss`, `surface`, `frost`, градиенты `bg-gradient-flux`,
`bg-gradient-prism`, `bg-gradient-aura`, `bg-gradient-flux-prism`,
тень `shadow-card-hover` и функцию плавности `ease-flow`.

## Правила

1. Не использовать плоские акценты — только градиенты.
2. Не использовать цвета вне палитры. Нужен новый — добавить токен.
3. Все переходы — с кривой `--ease-flow`, кроме явно указанных случаев.
4. Карточки тайтлов всегда 20px, панели — 28px.
5. Рейтинги, версии и размеры — только моноширинным шрифтом.
6. Любая анимация обязана отключаться при `prefers-reduced-motion`.
